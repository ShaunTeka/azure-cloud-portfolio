
# 🌐 Azure Networking Lab

Hands-on Microsoft Azure networking project documenting the configuration and management of Azure network resources.

## 📌 Project Overview

This project documents my hands-on experience working with networking services within Microsoft Azure.

## 🧰 Technologies

`Azure Virtual Network` `Subnets` `Network Security Groups` `Public IP Addresses` `Azure Portal`

## 🎯 Objective

The objective of this lab is to gain practical experience creating and configuring Azure networking resources, understanding network segmentation, controlling network traffic, and connecting Azure resources securely.
